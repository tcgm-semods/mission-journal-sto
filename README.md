# Mission Journal (STO-Style)

A Star Empire mod. Replaces the Mission Log window with a Star Trek
Online-style layout: a category sidebar, a persistent detail pane (no more
popup), and a trackable-mission HUD objective tracker.

See [`source/README.md`](source/README.md) for the full feature rundown.

## Install

Grab the latest `.semod` from [Releases](../../releases/latest) and drop
it into the Star Empire Mod Manager.
